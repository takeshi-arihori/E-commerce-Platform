# ADR-0008: AI の利用方針（実装は手で書き、AI はレビューする）

- 状態: 採用
- 日付: 2026-11-07

## 背景

このプロジェクトの第一の目的は、開発者本人のコーディング力の向上。AI にコードを書かせると速く進むが、設計と実装の判断を自分で行う機会がなくなる。

## 決定

| 作業 | 誰が行うか |
|---|---|
| ドメインモデリング（集約・コンテキストの分け方） | 開発者。AI は質問への回答とレビューのみ |
| 本番コード・テストコード | 開発者が手で書く。Cursor の補完と、数行程度の部分的な補助は可 |
| レビュー | Claude Code または Cursor（基準は [review.md](../engineering/review.md)） |
| docs・Issue・設定ファイルの下書き | AI が手伝ってよい。内容は開発者が確認して確定する |
| 調査・質問への回答 | AI。ただし答えのコードではなく、考え方と根拠を返す |

- AI はレビューでコードを変更しない。修正済みの完成版のコードも出さない（開発者が明示的に求めた場合だけ、短い例を示してよい）。
- AI 向けのルールは [AGENTS.md](../../AGENTS.md) を正本とし、Claude Code（`CLAUDE.md`）と Cursor の両方から読み込む。
- 教材の本文はリポジトリに転記しない。AI にも章番号とタイトルで参照させる。

## 採用しなかった案と理由

- AI に実装させ、開発者がレビューする: 学習の目的と逆になるため。

## 影響

- 開発の速度は遅くなる。その分、Task を小さく分けて1つずつ完了させる。
