## 要求ID

- `BR-XXX`: ビジネス要求
- `UR-XXX`: ユーザー要求
- `FR-XXX`: 機能要求
- `NFR-XXX`: 非機能要求
- `CON-XXX`: 制約

要求はNotionで検討し、確定した内容をGitHubへ反映します。
